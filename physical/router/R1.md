## 주요 역할

Cisco 2800 Router는 병원 Physical Network의 외부 네트워크 연결과 내부 트래픽 라우팅을 담당한다.

Fa0/0을 외부 네트워크 인터페이스(NAT Outside)로 구성하고, Fa0/1 및 Fa0/1.100을 내부 네트워크 인터페이스(NAT Inside)로 구성하였다.

Fa0/1.100 서브인터페이스에 IEEE 802.1Q VLAN 100을 적용하여 Catalyst 2950 스위치를 통한 내부 Core 네트워크 연결을 구성하였다.

RIPv2 및 Static Route를 통해 네트워크 경로를 관리하며, NAT Overload(PAT)를 사용하여 ACL 1에서 지정한 내부 주소의 외부 통신을 지원하도록 설정하였다.
